# Task 15-06 — Implementasi IA.09 setelah source disahkan

Status: [ ] **blocked-source** pada saat rencana ditulis. Dependency: **15,12–14; original keluarga ini disahkan owner**.

## Tujuan

Menyimpan dan menampilkan seluruh field IA.09 untuk tujuh skema, berdasarkan original yang saat ini belum tersedia terpisah. Task ini hanya satu keluarga instrumen; jangan mengerjakan keluarga lain di sesi yang sama.

## Source gate dan batas

Baca CONTEXT, FIELD_COVERAGE dan hasil task15. Owner harus menyediakan original yang lengkap dan menetapkan versi/cakupan. Judul pada MAPA02 atau daftar periksa tidak mendefinisikan field. Tanpa sumber tersebut, **berhenti pada status blocked**, tidak membuat input generik, soal, unit, KUK atau pertanyaan contoh. Jika owner menghapus keluarga ini dari scope, catat keputusan tertulis dan ubah matriks; AI tidak boleh mengambil keputusan itu.

Tiga role saja, no PDF, no generic workflow engine atau modul later. Auto-signature memerlukan consent jadwal dan tindakan sah. Semua GET read-only; hasil/observasi hanya tindakan nyata actor berwenang.

## Scope dan file

- `database/seeders/data/form-registry.json`: hanya keluarga IA.09.
- `database/seeders/data/field-maps/S1.json` sampai `S7.json`: row/field keluarga ini dengan source/page/label.
- `docs/FIELD_COVERAGE.csv`: ganti unresolved keluarga ini dengan field konkret; jangan mengubah skema lain tanpa source.
- `app/Http/Requests/InstrumentPayloadRequest.php`: validator keyed family/source version, role ownership dan allowed fields.
- `app/Http/Controllers/Asesor/InstrumentController.php` dan `Asesi/AssessmentExecutionController.php`: hanya bila original memberi kolom kepada role tersebut.
- `resources/views/instruments/ia09.blade.php` (baru): paper sections/rows/labels dari source, shared form/focused shell.
- `tests/Feature/CoreIA09Test.php` (baru).

## Perilaku

Setelah source tersedia, daftar setiap section/table/row/field, tipe, opsi asli, role pengisi, waktu capture, mandatory versus conditional dan signature/footer. Verifikasi isi teknis untuk S1–S7; shared layout bukan izin copy isi skema lain. Ikuti kelompok/unit/KUK versi assessment. Data master immutable, jawaban/temuan actual versioned, draft dapat disimpan, final memerlukan field lengkap dan actor tepat. Jika terdapat key jawaban atau instruksi hanya asesor, jangan kirim ke client asesi. Penggunaan keluarga ini mengikuti MAPA/AK01; kelengkapan form untuk semua skema tidak memaksa semua peserta menjalani semua metode. Pisahkan skor/fakta dari rekomendasi kompetensi.

Source yang masih ambigu menghasilkan pertanyaan owner dengan halaman/field spesifik. Isi acceptance di bawah tidak mengizinkan Gemini menebak field yang belum disebut di dokumen ini: bentuk final harus diturunkan dari original disahkan.

## Acceptance criteria

- [ ] Tidak ada unresolved/missing-source pada versi keluarga ini yang published; source/hash/page/field mapping lengkap S1–S7.
- [ ] Urutan, numbering, wording, grouping dan tabel layar mengikuti original; tidak menambah kolom paper untuk metadata internal.
- [ ] Setiap field round-trip dan validasi sesuai sumber; no fake value/N/A otomatis atau default K/BK.
- [ ] Role/assessment ownership, foreign unit ID, missing consent dan stale revision ditolak; GET tidak menulis.
- [ ] Draft/error/next action memakai komponen sama; no PDF button, no competing menus dalam assessment.

## Test sempit

`php artisan test --compact tests/Feature/CoreIA09Test.php`.

Gunakan data provider tujuh skema dari approved source registry, expected labels/counts diverifikasi original, bukan dihitung importer yang sedang diuji. Uji data kosong/conditional, unknown field/option, wrong actor/assessment, round-trip, draft versus final dan no automatic competence. Jangan full suite/build; browser sekali pada task23.

## Rollback dan handoff

Retire draft/source salah; record yang telah dipakai tetap mempertahankan payload+source version. Perbaikan field mapping lewat revision/migration explicit, bukan mengubah hasil lama. Commit scope keluarga ini, catat test/exit code dan owner decision pada EXECUTION_PLAN. Original dan file dirty owner tidak disentuh. Jika sumber belum lengkap, task tidak selesai.
