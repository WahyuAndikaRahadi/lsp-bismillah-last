## Aturan Penggunaan

- Jangan menganggap nomor urut file sama dengan kode form.
- Bandingkan dokumen bernama `ok`, `final`, `copy`, dan `Rev` sebelum menentukan sumber utama.
- Form yang tidak ada pada satu skema tidak boleh dipaksakan hanya karena tersedia pada skema lain.
- Konten unit, KUK, pertanyaan, tugas praktik, kelompok pekerjaan, dan soal harus terikat pada skema masing-masing.
- Template operasional BA, daftar hadir, dan pleno bukan pengganti dokumen MUK; ketiganya melengkapi workflow sertifikasi.
- Render halaman untuk memeriksa layout. Ekstraksi teks saja tidak cukup untuk tabel, checkbox, area tanda tangan, header, dan footer.
